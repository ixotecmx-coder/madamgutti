# MadameGutti Landing Page

Landing page moderna para una peluquería en Miami, lista para publicar en GitHub Pages.

## Cómo usar en GitHub Pages

1. Crea un repositorio nuevo en GitHub.
2. Sube los archivos `index.html`, `styles.css`, `script.js` y `README.md`.
3. Ve a **Settings > Pages**.
4. En **Build and deployment**, selecciona la rama `main` y la carpeta `/root`.
5. Guarda los cambios y abre la URL que GitHub Pages genere.

## Personalización rápida

- Cambia el número de WhatsApp en `index.html` y `script.js`.
- Cambia textos, horarios o ubicación en `index.html`.
- Cambia colores en `styles.css`, dentro de `:root`.
